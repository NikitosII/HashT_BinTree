## Описание

Проект представляет собой консольное приложение на C++, которое позволяет пользователю вводить данные из файла, строить хеш-таблицу с бинарными деревьями для обработки коллизий, выводить данные и искать элементы.

## Функциональность

- **Ввод данных**: Пользователь может ввести данные из файла, указав путь к файлу в командной строке.
- **Вывод данных**: Пользователь может вывести все элементы хеш-таблицы.
- **Поиск данных**: Пользователь может искать элементы в хеш-таблице по ключу и значению.

## Использование

1. Склонируйте репозиторий:
    ```sh
    git clone <URL репозитория>
    ```
2. Перейдите в директорию проекта:
    ```sh
    cd <имя директории проекта>
    ```
3. Скомпилируйте проект:
    ```sh
    g++ -o HashT_BinTree HashT_BinTree.cpp HashM.cpp Item.cpp Tree.cpp
    ```
4. Запустите программу, указав путь к файлу с данными:
    ```sh
    ./HashT_BinTree <путь к файлу>
    ```
    Например:
    ```sh
    ./HashT_BinTree data.txt
    ```

### Пример использования

1. Создайте текстовый файл `data.txt` с содержимым:
    ```
    da 100
    lho 44
    hol 15
    f 11
    rus 777
    ```
2. Скомпилируйте и запустите программу:
    ```sh
    g++ -o HashT_BinTree HashT_BinTree.cpp HashM.cpp Item.cpp Tree.cpp
    ./HashT_BinTree data.txt
    ```
3. Следуйте инструкциям в меню:
    ```
     Menu:
    1) Data input
    2) Data output
    3) Search data
    0) Exit
    Select a menu item: 1
    ```
    После выбора пункта 1 программа считает данные из файла.

4. Выберите пункт 2 для вывода данных:
    ```
     Menu:
    1) Data input
    2) Data output
    3) Search data
    0) Exit
    Select a menu item: 2
    ```
    Программа выведет все элементы хеш-таблицы:
    ```
    by default, elements of binary trees are displayed in ascending order
    Item 2:
    Key: f, Data: 11
    Item 3:
    Key: hol, Data: 15
    Key: lho, Data: 44
    Item 6:
    Key: rus, Data: 777
    Item 7:
    Key: da, Data: 100
    ```

5. Выберите пункт 3 для поиска данных:
    ```
     Menu:
    1) Data input
    2) Data output
    3) Search data
    0) Exit
    Select a menu item: 3
    ```
    Введите ключ и значение для поиска:
    ```
    Enter search (key data): f 11
    The element was found in the hash table.
    Continue?(0/1): 0
    ```

## Структура проекта

- `HashM.h` и `HashM.cpp`: Определение и реализация класса `Hashmap`, который управляет хеш-таблицей.
- `Tree.h` и `Tree.cpp`: Определение и реализация класса `BinaryTree`, который представляет бинарное дерево для обработки коллизий.
- `Item.h` : Определение и реализация класса `Item`, представляющего элемент хеш-таблицы.
- `HashT_BinTree.cpp`: Основной файл программы, содержащий меню для взаимодействия с пользователем.
